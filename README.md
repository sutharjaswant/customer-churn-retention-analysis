\# Customer Churn and Retention Analysis



\## Project Overview

This project analyzes customer churn in a telecommunications company to understand why customers leave and identify opportunities to improve customer retention.



\## Dataset

\- Dataset: IBM Telco Customer Churn

\- Records: 7,043 customers

\- Columns: 21

\- Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn



Download the CSV file and save it as `data/Telco-Customer-Churn.csv`.



\## Tools and Technologies

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- SQL and SQLite

\- Power BI

\- Jupyter Notebook

\- Git and GitHub



\## Project Workflow

1\. Data loading and inspection

2\. Data cleaning and preprocessing

3\. Exploratory data analysis

4\. Churn analysis by contract, tenure, payment method, and services

5\. High-risk customer identification

6\. SQL analysis

7\. Power BI dashboard

8\. Business insights and recommendations



\## Key Business Insights

\- Overall churn rate: 26.54%

\- Month-to-month contract churn: 42.71%

\- One-year contract churn: 11.28%

\- Two-year contract churn: 2.85%

\- Churn among customers with 0–12 months of tenure: 47.68%

\- Churn among customers with 49–72 months of tenure: 9.51%

\- Electronic check payment churn: 45.29%

\- Churn among customers without online security: 41.78%

\- Churn among customers without technical support: 41.65%

\- High-risk customers identified: 686

\- High-risk customer churn rate: 73.03%

\##Project Dashboard

Power BI dashboard showing customer churn, retention patterns, and high-risk customer segments.

\## Recommendations

\- Improve customer onboarding during the first year.

\- Encourage suitable long-term contracts.

\- Investigate payment-related concerns.

\- Improve awareness of security and technical support services.

\- Prioritize retention efforts for high-risk customers.

\## How to Run

1\. Download the dataset and place it in the `data` folder.

2\. Create and activate a Python virtual environment.

3\. Install dependencies using `pip install -r requirements.txt`.

4\. Open the notebooks in VS Code or Jupyter.

5\. Run the notebook cells in order.

6\. Open the Power BI dashboard to explore the results.



\## Conclusion

The analysis highlights relationships between customer churn and factors such as contract type, tenure, payment method, and service usage. These insights can help a business develop targeted customer retention strategies.
